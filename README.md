## ✨ 核心黑科技 (Killer Features)

- 🧠 **RAG 全局参谋数据库**：可挂载一整本《工业科技树》或《魔法阵列大全》作为底层数据库。一键开启后，AI 在生成设定时将被**强制要求参考**这些底层逻辑，彻底告别 AI 凭空捏造的"玄幻脑补"。每个知识库条目还支持来源分组、分类筛选与批量开关，想挂哪本就挂哪本。
- 🎓 **AI 语法与格式克隆引擎**：无论你习惯用 **W++** 伪代码还是自定义的 XML 标签，只需粘贴一段样本，工坊 AI 即可自动提取标点、换行、结构等语法特征，并在后续的生成与写入中 **100% 完美复刻**你的排版习惯，让 AI 的输出永远贴合你的文风。
- 🎯 **SillyTavern 生态级深度兼容**：完全吃透酒馆底层逻辑。无损导入/导出 JSON/YAML 格式世界书，完美解析酒馆现代 Prompt Manager（预设管理器），支持**一键导入酒馆预设**与 `{{char}}`、`{{user}}` 等宏标记的自适应渲染。
- 🌌 **神经拓扑星图可视化**：内嵌 ECharts 力导向图渲染引擎。一键将孤立的文本设定转化为错综复杂的视觉知识网络，支持点击节点直达编辑，设定关联一目了然，世界观"骨架"尽收眼底。
- 🤖 **全知 AI 创作引擎**：具备原生 Function Calling / Tool Calling 能力，支持单条设定扩写/润色、长篇设定的批量提取，以及针对易误触发逻辑的智能合规审查与全局层级调优。自带 `<think>` 思考过程屏蔽与流式打字机效果，体验丝滑。
- 💾 **极客级无尽安全存储**：突破传统 LocalStorage 5MB 限制，采用 IndexedDB 超大容量存储 + 断网修改时间戳合并机制 + 自动快照备份。你的几万字设定集与所有 API Key **永远只存在你的本地设备上**。

## 🛠️ 本地离线使用（手把手保姆级教程）

> **💡 零门槛提示**：本软件**不需要安装任何后台程序**！不需要 Python、不需要 Node.js、不需要输入任何复杂命令。就像打开一张图片或普通网页一样简单！

### 📂 第一步：下载软件文件到电脑

- **方法一（适合绝大多数新手用户）：**
  1. 点击本页面右上角的绿色 **`Code`** 按钮。
  2. 在弹出的菜单最下方点击 **`Download ZIP`**（下载压缩包）。
  3. 下载完成后，将压缩包**解压**到你电脑的任意文件夹（比如桌面）。

- **方法二（适合懂 Git 的开发者）：**
  - 在终端运行命令：`git clone https://github.com/tian2418671-sys/worldbook-workshop.git`

### 🖱️ 第二步：鼠标双击，直接启动

1. 打开刚刚解压出来的文件夹。
2. 在里面找到一个名字叫 **`index.html`** 的文件：
   - *（注：如果你的电脑设置了隐藏扩展名，它会显示为一个带着浏览器图标、名字叫 `index` 的文件）*
3. **直接用鼠标左键双击打开它**（推荐使用 Chrome、Edge、Firefox 或 Safari 浏览器）。
4. 🎉 恭喜你！《世界书工坊》已经成功在浏览器里跑起来了！
   - *小贴士：按键盘 `Ctrl + D` 把这个页面加入浏览器书签，或者把 `index.html` 发送到桌面快捷方式，以后想用时一键就能打开！*

> 💡 **三步速记**：下载 → 解压 → 双击 `index.html`，就这么简单！

## ❓ 常见疑惑解答（新手必看）

* **问：断网或者没有网络时还能用吗？**
  * **答：完全可以！** 网页的所有功能代码和数据都在你的本地电脑里。就算把网线拔掉，你依然可以随时打开网页编辑设定、查看拓扑星图、管理词条。
  * *(注：只有在你需要调用在线 AI 帮写/扩写时才需要连网；如果配置的是本地运行的大模型，完全断网也能用 AI 功能！)*

* **问：我关闭浏览器或者关机后，我的世界书会丢失吗？**
  * **答：绝对不会！** 你的每一次修改都会**自动保存**在浏览器的本地数据库（IndexedDB）中。下次重新双击打开网页，你之前写的所有内容都会完好无损地呈现在面前。
  * *(建议：重要的数据也可以定期点击界面上的「导出」按钮，下载保存一份 JSON 文件到电脑硬盘里，双重保险！)*

* **问：我需要付费或者注册账号才能用吗？**
  * **答：100% 免费开源，无需注册任何账号**，数据完全属于你个人。

* **问：换了电脑或浏览器，我的数据能带走吗？**
  * **答：当然可以！** 使用界面上的「导出」功能下载一份 JSON 备份，再到新设备上打开网页用「导入」功能恢复即可，数据无缝迁移。

## 📦 开发者：一键部署自动化 (Deployment)

在 `github-deploy` 目录下运行 `.\deploy.ps1` 即可完成 **同步 → 提交 → 推送 → 开启 Pages** 全流程：

```powershell
cd github-deploy
.\deploy.ps1                        # 一键部署（自动把父目录源文件同步为 index.html）
.\deploy.ps1 -CommitMessage "更新日志"   # 指定提交信息
.\deploy.ps1 -SourceFile ..\index.html  # 指定其它源文件
.\deploy.ps1 -RepoName my-lorebook -Private   # 部署到新私有仓库
.\deploy.ps1 -SkipSync -SkipPush           # 只提交当前内容，不推送
```

**脚本行为：**

1. 自动同步源文件为 `index.html`。
2. 有变更时自动 `git add/commit`（未指定提交信息则自动带时间戳）。
3. 检查 `gh` 登录 → 推送 `main` 分支（仓库不存在时自动创建）。
4. 幂等地开启/更新 GitHub Pages（从 `main` 分支根目录服务）。

> **前置要求**：已安装并登录 GitHub CLI（`gh auth login`），且本目录为 Git 仓库。
